# PDF 가이드북 배포처 리서치

이 가이드의 타깃은 웹 접근성 의무를 진 조직의 실무자입니다. 구체적으로는 ESG·법무·총무 담당자, 공공기관 및 공공사업 수주 기업, 쇼핑몰/금융 운영 담당자, 그리고 웹 제작·개발 업체입니다. 즉 전형적인 **B2B 의사결정권자**입니다. 이 타깃 특성에 맞춰 배포 채널을 우선순위로 정리합니다.

## 배포 목적부터 정하기

PDF 배포처는 "무엇을 얻고 싶은가"에 따라 갈립니다.

- **리드 수집**(이메일·연락처 확보 → 영업 전환): 이메일 게이트 + 타깃 광고
- **검색 노출/SEO**(장기 오가닉 유입): 자사 블로그 + 문서 호스팅
- **신뢰도·브랜딩**(전문성 각인): 자사 사이트 + 업계 네트워크

세 가지를 동시에 노리되, 보통 **리드 수집**을 1순위로 둡니다. 좋은 가이드는 리드 마그넷(lead magnet)으로서 가치가 크기 때문입니다.

## 타깃에 맞춘 권장 조합

### 1순위 — 자사 사이트 게이트 + 리멤버
- **자사 사이트**: 〈04_AI대체텍스트〉 글 하단의 이메일 입력 폼처럼, PDF를 이메일 게이트 뒤에 둡니다. website.com/guide에서 본문을 무료 공개하되, 전체 PDF는 이메일 입력 후 다운로드.
- **리멤버**: 이 가이드 타깃(ESG·법무·공공·개발 담당자)이 정확히 리멤버의 직장인 DB와 겹칩니다. 직무·산업으로 타깃팅해 "웹 접근성 의무, 우리 회사도 대상일까요? 체크리스트 무료 다운로드" 같은 소재로 리드를 모읍니다. 명함 기반 자동 입력이라 전환율이 높습니다.

### 2순위 — 자사 블로그 SEO + 링크드인
- 6개 챕터를 블로그 글로 공개(이미 작성한 통일 콘텐츠 활용)해 "웹 접근성", "장차법 의무 대상", "대체텍스트 작성법" 등 검색어로 오가닉 유입을 만듭니다. 각 글 하단에서 PDF 다운로드로 연결.
- 링크드인에 챕터별 핵심을 카드뉴스/포스트로 발행하고 PDF 링크를 연결합니다.

### 3순위 — 임시·보조 채널
- 정식 사이트 개발 전이라면 **Notion 공개 페이지**로 먼저 배포해 반응을 봅니다.
- 확보한 리드에는 **뉴스레터**로 후속 콘텐츠를 보내 관계를 이어갑니다.

## 실행 시 체크포인트

1. **UTM 파라미터**: 채널마다 다른 UTM을 붙여 어디서 온 리드인지 추적합니다. (예: utm_source=remember / linkedin / blog)
2. **게이트 강도 조절**: 이메일만 받을지, 회사·직무까지 받을지. 정보를 많이 요구할수록 전환율은 떨어지지만 리드 품질은 올라갑니다.
3. **본문 일부 공개**: 전체를 막지 말고 챕터 본문은 웹에 공개해 SEO를 살리고, "PDF 한 권 정리본"만 게이트 뒤에 둡니다.
4. **QR 연결**: PDF 안 CTA의 QR은 website.com/guide로 연결해, 오프라인(인쇄)에서도 웹으로 유입되게 합니다.
5. **개인정보 처리**: 이메일·연락처 수집 시 개인정보 수집·이용 동의를 반드시 받습니다.
