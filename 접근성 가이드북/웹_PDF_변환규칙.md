# 웹 → PDF 변환 시 형식 변화 가이드

같은 콘텐츠라도 웹과 PDF는 사용 맥락이 다르므로 레이아웃을 다르게 가야 합니다. 함께 제공한 〈03_PDF_가이드북_샘플.pdf〉가 아래 규칙을 실제로 구현한 예시입니다.

## 핵심 차이 요약

| 요소 | 웹 버전 | PDF 버전 | 이유 |
| --- | --- | --- | --- |
| 레이아웃 | 3컬럼 (좌측 목차 / 본문 / 우측 앵커) | 1컬럼, A4 단면 | PDF엔 사이드바 개념이 없고 인쇄·뷰어 가독성이 우선 |
| 페이지 이동 | 좌측 고정 사이드바, GNB | PDF 북마크(목차) 패널 | 화면 스크롤 vs 페이지 단위 |
| 내부 링크 | 클릭 가능한 하이퍼링크 | "→ N페이지 참고" 텍스트 | 종이/오프라인에서도 찾아갈 수 있어야 함 |
| CTA | 이메일 입력 폼 + 버튼 | QR 코드 + 단축 URL | PDF에선 폼 입력 불가, QR이 웹으로 연결 |
| 표 | 가로 스크롤·반응형 | A4 폭에 맞춤, 넘치면 페이지 분할 | 고정 폭 매체 |
| 헤더/푸터 | GNB(상단 고정) | 페이지 번호 + 가이드명(하단) | 인쇄물 관례 |
| 표지 | 없음 (히어로 섹션) | 별도 표지 1페이지 | 문서로서의 완결성 |
| 챕터 전환 | 페이지 라우팅 | 챕터 구분 페이지 삽입 | 종이책 같은 흐름·휴지 |
| 색상 | 자유롭게 사용 | 배경 채색 최소화 권장 | 인쇄 시 잉크 소모·가독성 |

## PDF 문서 구조 (권장 순서)

```
1. 표지            — 타이틀, 부제, 발행 주체, 연도
2. 목차            — 챕터별 제목 + 시작 페이지 (PDF 북마크 연동)
3. 챕터 구분 페이지  — 챕터 번호 + 제목 + 리드 (각 챕터 시작마다)
4. 챕터 본문        — 1컬럼, 표/리스트/인용 포함
5. (반복) 3~4
6. 부록            — 업종별 체크리스트, 좋은 예/나쁜 예 대조표
7. CTA 페이지       — QR + 단축 URL로 웹 가이드 유도
```

## 변환 시 주의할 점

1. **내부 링크 전부 페이지 참조로 치환**: 웹의 〈대체텍스트 작성 7원칙〉 링크 → PDF에서는 "→ 14페이지". 페이지 번호는 최종 조판 후 확정해야 하므로, 변환 자동화 시 앵커-페이지 매핑 테이블을 둡니다.
2. **'다음 읽을거리'·'이전/다음' 페이저 제거 또는 변환**: 웹 전용 네비게이션이므로 PDF에선 빼거나 "→ N페이지"로 바꿉니다.
3. **이미지 해상도**: 인쇄까지 고려하면 최소 150dpi, 화면 전용이면 96dpi로 충분합니다.
4. **한글 폰트 임베딩 필수**: Noto Sans CJK KR 등 한글 글리프가 포함된 폰트를 PDF에 임베드해야 다른 PC에서 깨지지 않습니다. (이번 샘플은 Noto Sans CJK KR 사용)
5. **표가 페이지 경계에 걸칠 때**: 행 단위로 분할되도록 처리하고, 가능하면 표 머리행을 다음 페이지에 반복합니다.
6. **CTA의 QR은 실제 발급 필요**: 샘플은 자리만 잡아둔 상태이며, 배포 시 website.com/guide로 연결되는 QR 이미지를 삽입합니다.

## 제작 방식 (이번 샘플 기준)

- **HTML/CSS로 PDF용 레이아웃을 별도 작성** → weasyprint로 변환했습니다.
- 웹용 HTML을 그대로 쓰지 않고, `@page` 규칙(여백·페이지번호·표지 예외)과 1컬럼 구조를 적용한 PDF 전용 템플릿을 따로 둔 점이 핵심입니다.
- 같은 마크다운 본문을 소스로 쓰되, 웹 템플릿과 PDF 템플릿 2벌로 렌더링하면 콘텐츠 1벌 → 출력 2종을 유지보수할 수 있습니다.
