# 웹 접근성 가이드 — 콘텐츠 형식 통일 규칙 (Style Guide)

6개 목차(및 향후 추가될 목차)에 공통 적용하는 형식 규칙입니다. 모든 문서는 아래 구조를 따릅니다.

---

## 1. 문서 골격 (고정 순서)

```
# H1 제목 — 부제 (페이지당 1개, 형식: "핵심 키워드 — 한 줄 설명")
[리드 문단]  ← 2~3문장. 이 글이 답하는 질문 + 다룰 범위 요약

## H2 본문 섹션 1
### H3 하위 섹션 (선택)

## H2 본문 섹션 2
...

## 자주 묻는 질문   ← 항상 이 제목으로 통일 (FAQ → "자주 묻는 질문")

## 다음 읽을거리   ← 내부 링크 모음 (선택)

---
**출처 및 참고자료**   ← 있는 경우만. 구분선(---) 뒤에 배치

[CTA 블록]   ← 모든 페이지 동일 (PDF 다운로드)
```

---

## 2. 제목 레벨 규칙

| 레벨 | 용도 | 개수 |
|---|---|---|
| `#` (H1) | 페이지 대제목 | 페이지당 1개 |
| `##` (H2) | 주요 섹션 | 제한 없음 |
| `###` (H3) | H2 하위 구분 | 필요 시만 |
| `####` (H4) | 사용하지 않음 | 0 |

- H1 형식: `핵심 키워드 — 한 줄 설명` (전각 대시 `—` 사용)
- 기존에 `##`로 시작하던 목차 1·2·5는 `#`로 승격.

## 3. 리드 문단 규칙

- 모든 페이지는 H1 바로 아래 리드 문단으로 시작.
- 2~3문장: ① 독자의 질문/문제 제기, ② 이 글이 다루는 범위.
- 굵은 글씨·리스트 없이 평문.

## 4. FAQ 규칙

- 제목은 항상 `## 자주 묻는 질문`으로 통일.
- 각 질문은 `**Q. 질문**` → 답변 평문 형식.
- 기존 `Q1./Q2.` 번호는 유지하되 `**Q1. ...**` 굵게 통일.

## 5. 표 규칙

- 모든 비교·정리 데이터는 마크다운 표로 통일 (목차 5의 서술형 표 → 표 형식 전환).
- 헤더 행은 굵게 자동 처리, 좌측 정렬 기본.
- 표 안에서는 굵은 글씨 최소화.

## 6. 내부 링크 표기 통일

- 같은 가이드 내 다른 글 참조: `〈글 제목〉` (홑화살괄호)로 통일.
- 기존 백틱(`...`)·굵은 글씨 방식 → 모두 `〈 〉`로 변경.
- 웹에서는 실제 하이퍼링크, PDF에서는 "→ N페이지 참고"로 변환.

## 7. CTA 규칙

- 모든 페이지 맨 아래 동일한 CTA 블록 배치.
- 형식:
  ```
  > **웹 접근성 체크리스트 PDF 무료 다운로드**
  > 전체 6개 챕터를 한 권으로 정리한 가이드북을 받아보세요.
  > [이메일 입력] [무료 다운로드]
  ```

## 8. 출처 규칙

- 본문 안 인라인 출처 표기(예: `Nepla`, `Lbox`, `CaseNote` 등 꼬리표)는 제거.
- 출처는 문서 맨 끝 `**출처 및 참고자료**` 블록에 모아서 정리.

## 9. 강조 규칙

- 굵게(`**`)는 핵심 용어·수치에만. 한 단락에 2~3개 이내.
- 기울임은 인용·문서명에만.
- 본문에서 과도한 굵게 처리 제거.

## 10. 톤 & 표기

- 문체: 정중한 '~습니다' 체로 통일.
- 숫자: 천 단위 콤마(예: 3,000만 원), 퍼센트는 % 기호.
- 법령명: 〈장애인차별금지법〉이 아니라 본문에서는 그냥 장애인차별금지법(법령명은 링크 대상 아님).
